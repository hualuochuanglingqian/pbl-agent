# PBL 医学教案工作台

基于病例生成 PBL（Problem-Based Learning）教案的本地智能体：**教材检索 + 文献检索 → 逐问题生成学习内容/参考文献/临床应用 → 思维导图 → Word / PPT 导出**，全程支持二次修改与格式调整。

## 一、功能总览

| 工作区 | 功能 |
|---|---|
| ① 病例与问题 | **先总结、后出题**：草稿独立保存；先从病例+草稿生成独立的个人问题总结目录，再据总结生成全量问题清单。问题清单可单独增删改，不反向修改草稿总结；题库重建时按文本匹配保留旧答案/引用。**实际作答题**多选默认全选，仅控制批量生成和 Word 答案范围；Word 的小组问题与独立个人总结仍包含全量内容，未选题只省略答案。旧案例的题目总结继续作为兼容回退。**病例分幕存档**：同一病例可分幕存档到 `cases/acts/{系列}__act{n}.json`；可勾选前幕答案并入 Word。|
| ② 内容生成与修改 | 两种生成模式，均为**两步走**（先生成学习内容，再把**病例+问题+学习内容**单独交给模型撰写临床应用）：**🚀 检索生成**（学习内容严格依据教材检索结果）与 **💬 直接生成＋审校**（模型先答，审校智能体对照教材修订补出处）；学习内容支持**分层编号（1./（1）/①）**与**表格**（对比类内容自动生成，界面 Markdown 可编辑）；逐字段可编辑、可带指令局部重生成；逐题「🕵️ 智能体审校修订」；中文文献/书籍手动导入；**批量生成逐题汇总失败与注意信息，失败时内容保留原样**；病例超过 6000 字只取前 6000 字并界面提醒；**学习内容为通用知识、不联系病例**（病例分析集中在实际应用，避免两者重叠）；**实际应用 250 字左右、不超过 500 字**且不复述学习内容；**学术自然化**：生成提示词内置去机器文风规范（禁套话、句长错落、术语统一、路标词减半），每题另有「🖋 自然化润色」按钮做语言层重写（数据与 [n] 引用标注程序校验零改动，并报告改写度） |
| ③ 思维导图 | **疾病中心知识导图**：PBL 最后一节课结束后单独生成——以疾病为根，**按你自己设定的分支框架**组织（默认：病因学（病因、诱因、危险因素）／发病机制／诊断及鉴别诊断／治疗／预后，一行一个、可增删调序；**「预防」默认不单列**，内容落到治疗的二级预防/患者教育与病因学的诱因控制里）；**老师要求写在同一个输入框里**（如「不单列治疗，并入诊断」「每个分支不超过 4 个要点」），老师要求不单列的分支直接删掉即可——模型会把内容并入最贴合的分支，**不留空壳**；**必须结合本病例**：病人身上的具体表现/数值/检查结果**就地标黄加下划线**（`==本例：尿蛋白 2+==`），**不单列「结合病例」分支**，图例固定标在左下角；支持上传多份 Word/PDF 补充资料（提取文本一并纳入）；**版式照 XMind 默认思维导图做**：中心为纯黑粗体文字（无底框）、一级分支为实色圆角块 + 黑字、二级以下纯文字、
分支线为 2pt 等宽曲线/圆角肘形、每支一色，2 倍超采样后缩小，边缘干净；
**连线样式可选**（XMind 默认／主干式／曲线／直线／不画连线）；Markdown 可编辑（`==…==` 即病例标注）；导出 **.xmind（黄底一并带走，XMind 里可继续编辑）** / PNG / 交互 HTML / FreeMind .mm（默认不进 Word） |
| ④ 文献检索 | **先检索文献，再导出 Word/PPT**。自选方向 + 提示词（中文自动转英文检索式），三类筛选：**时间范围**（近 N 年 / 自定义年份区间 / 不限）、**影响因子范围**（下限 / 上限）、**文献类型**（只要研究型，自动排除综述/指南/社论/病例报道 ／ 只要综述与荟萃分析 ／ 全部）；另有「只看可取图」开关（已验证可下载出版社 Frontiers/PLOS/BMC/Nature 系，**保证取到原文图片**）。多级检索式降级**累积候选**（严格 AND 命中排最前、宽松命中垫底）、按影响因子排序，显示简介/创新点/IF/是否可自动取图。选定后从开放期刊 PDF 自动提取 **2~4 张能证明结论的关键图** + 中文说明，并生成**研究过程 A→B→C→D 四步链**、核心结论、与病例的联系、局限性；逐项可改，也可「按提示词二次修改」；可切换「整图/分图」。 |
| ⑤ 导出 Word | 支持三种模板：内置《PBL作业word模板》/ **用户上传的自定义模板**（结构类似即可，找不到标准结构时自动追加模式）/ 无模板简洁样式；**结构对齐教师点评要求**：全部问题 → **小组问题（原序）** → **个人总结（1. / 1.1 / 1.1.1 分层目录，按层级缩进）** → 关键词 → 问题解答（**默认按个人总结顺序**，可关掉）→ **附录：前幕问题解答（回顾）**（① 区勾选哪几幕就并入哪几幕，含该幕病例摘要与要点）→ **文献分享**章节；问题数量自动适配；**标题、姓名/班级/学号留空自行填写**；正文编号段顶格、普通段**首行缩进两字符**、文献条目缩进、引用为**上标 [n]**；参考文献 GB/T 7714-2015（≤5 条，教材 [M] 含主编/页码合并）；正文、表格与出处中的 `[Tn]/[Pn]/[Rn]` 统一解析；教材书目由本次检索命中或明确书名出处建立，无法恢复的旧裸 `[Tn]` 会提示核对而不猜书名；内容自动去【】、禁止叠加编号；可调用本机 Word 导出预览图 |
| ⑥ 生成 PPT | **问题 PPT**（分工：每人 1~2 个问题）：问题在上 → 学习内容居中（自动 1~2 页、含表格）→ 参考文献在底部，可署名；**PPT 模板库**：默认天医大答辩通用模板（沿用其版式设计），可上传自己的 .pptx 模板加入库中选用；正文字号**不小于 16 号**（参考文献除外），图片可按「整图/分图」切换；支持文字编辑与「按提示词二次修改」，调用本机 PowerPoint 导出预览图。**进阶：PPT Master 设计版**——一键把案例导出为 ppt-master-comfyui 技能项目（素材 Markdown + 文献图片 + Stage-1 沟通契约）并启动确认页，确认后在对话中由智能体完成设计排版与导出 |

**推荐顺序**：① 填病例与问题草稿 → 从草稿生成个人问题总结 → 依据总结生成全量问题清单 → 用户删减/补题并选择实际作答题 → ② 只对已选题生成学习内容 → ③ 疾病导图（最后一节课）
→ **④ 文献检索（选一篇文献）→ ⑤ 导出 Word（自动带上文献分享章节）→ ⑥ 生成 PPT**。
先检索文献再导出 Word，是为了让 Word 里的「文献分享」用的是你真正选中的那篇文献。

### 文献分享 PPT：一页速览

版式参照同学用的《文献分享_一页速览_v2.pptx》，**背景默认省略**，一页放完：
顶部 **2~4 张关键图**（每图下方一行粗体图注，抓最能证明结论的图）→ 左下**核心结论**框 →
右下**与病例的联系**框 → 底部 **A→B→C→D 研究过程流程条**（假设 → 方法 → 验证 → 因果）→
最底参考文献；**备注页**写好讲解思路（连起来就是口头汇报的串词）。图片数量不同会自动换版式
（1/2/3/4 张各有对应排法），无图时退化为「研究思路」整条横排。

### 病例分幕怎么用

1. ① 区填好第一幕的病例与问题后，展开「🎬 病例分幕存档」→ 幕号填 1、写个幕标题（如「首次就诊」）→ **💾 保存本幕存档**；
2. 下次课点 **＋ 新建下一幕**：系统先存好当前幕，再开一份新案例——**病例原文沿用**（在上面追加第二幕的新信息即可），
   问题清空，系列名不变；
3. 想回看/改第一幕：在该系列的存档列表里点 **载入**；
4. 做第二幕的 Word 时，在同一个展开框里勾选「并入第一幕」——那几幕的**问题解答整段**会作为
   **附录：第一幕 问题解答（回顾）** 放进文末，与当时提交的版本一字不差（不是重新生成）。

存档是整份案例 JSON（含学习内容、个人总结、导图、文献分享），所以换幕不丢东西；
删掉存档文件不影响当前工作区。`cases/history/` 的自动快照仍然照常保留，两套机制互不干扰。

### 思维导图的病例标注

老师一般要求「结合病例」，但不让单列一个「结合病例」分支。这里的做法是**就地标注**：

```markdown
- 诊断及鉴别诊断
  - 尿液与肾功能检查
    - 尿常规：潜血 3+、蛋白 2+，镜检 RBC 221.6/HP
    - ==本例：eGFR 19.74，Cr 239.6μmol/L，CysC 2.58mg/L==
```

`==…==` 里的内容渲染成**黄底 + 下划线**，左下角自动带图例；.xmind 里同样带黄底
（在 XMind 里继续编辑仍认得出），交互 HTML 里显示为高亮。生成后可随时在 Markdown 编辑框里
增删 `==`，点「✅ 应用修改」即生效。

PNG 的版式照 XMind 默认导出的效果做（白底 / 中心是黑色粗体文字、**没有底框** / 一级分支是实色圆角块 +
**黑字** / 二级以下纯文字黑字），画布按内容自适应，2 倍超采样后缩小，
所以连接线和文字边缘是平滑的；正文按像素宽度换行，西文和数字整词不拆（`Gd-IgA1`、`C1GALT1` 不会被劈开）。

**PNG 两种出图方式**（③ 区「PNG 出图方式」）：
内置绘制——不联网、可调连线样式，风格由本项目绘制；
浏览器渲染——用本机 Edge/Chrome 无头模式把 markmap（d3）渲染成 PNG，曲线与配色是导图库的成品效果，
最像思维导图软件，需要联网加载 CDN；失败会自动退回内置绘制。

**默认档直接照 XMind 内置主题的数值做**（不是目测）：中心为纯黑粗体文字 30pt/800（主题里
`fill-pattern: none`，所以没有黑底框），分支线 curve、2pt；一级为 6 色实色圆角块 + **黑字** 18pt/500，
分支线 roundedElbow（圆角肘形）、2pt；二级以下纯文字 14pt/400，分支线同为 roundedElbow、2pt；
调色板恰为 XMind 的 #FF6B6B #FF9F69 #97D3B6 #88E2D7 #6FD0F9 #E18BEE，
按顺时针轮转分配到各一级分支（左右两翼不重复用色）；line-tapered: none，不做楔形。
这些数值取自本机安装的 XMind 自带模板 mind_map.xmind 的 content.json → theme
（提取脚本见 tools/asar_read.py、tools/xmind_zip.py）。导出的 .xmind 会把这份默认主题一并写进
content.json，所以在任何人的 XMind 里打开都是这套样子，不受对方当前主题影响。

**连线／版式样式可选**（③ 区「连线样式」，随案例保存）：
`XMind 默认`（中心黑字无框、一级实色块黑字、二级以下纯文字、根到一级为曲线、再往下为圆角肘形，
2pt 等宽，默认）／`主干式`（竖线 + 短横桩，同层共用一条线）／`曲线`（每个分点一条等宽弧线）／`直线`／`不画连线`。
XMind 默认档还会把层间距放大，否则曲线被压成近乎垂直的线，看着就乱。

## 二、快速开始

```bash
# 1. 安装依赖（国内网络建议镜像源）
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple

# 2. 配置 API Key：编辑 .env（参照 .env.example）
#    ZHIPUAI_API_KEY=你的智谱APIKey（默认对话模型 + 教材向量化，必配）

# 3. 启动
双击 启动系统.bat     # 或：streamlit run app.py
```

### 切换对话模型供应商（可选）

对话模型支持智谱 / DeepSeek / OpenAI / 任意 OpenAI 兼容端点，改 `.env` 后重启即可：

```ini
PBL_PROVIDER=deepseek          # zhipu（默认）/ deepseek / openai / custom
DEEPSEEK_API_KEY=sk-...        # openai 用 OPENAI_API_KEY，custom 用 PBL_API_KEY + PBL_BASE_URL
PBL_MODEL=deepseek-chat        # 缺省：glm-4-flash / deepseek-chat / gpt-4o-mini
```

说明：
- **教材 RAG 向量化固定使用智谱 embedding-3**（DeepSeek 无 embedding 接口），因此无论换哪家，`ZHIPUAI_API_KEY` 都要保留；
- 国内端点（智谱/DeepSeek）强制直连不受系统代理影响；OpenAI/custom 默认跟随系统代理，`PBL_TRUST_ENV=0` 可强制直连；
- 提升智谱质量：`PBL_MODEL=glm-4-plus`（或便宜的 `glm-4-air`）。

> **无 API Key 也能跑**：自动进入演示模式（载入演示案例 → 生成演示内容 → 导出 Word/PPT），适合先熟悉流程与现场演示。
>
> **网络自愈**：系统会自动检测本机系统代理（Clash/V2Ray 等）是否可用——智谱 API 强制直连（国内服务），代理隧道损坏时 PubMed 检索自动绕行直连，无需手动关代理。

## 三、教材检索库（RAG）用法

1. 把十版教材电子版（PDF / docx / txt / md）放进 `knowledge_base/books/`（或界面上传）；
2. 侧边栏「📚 教材知识库」→ 点 **建立/重建索引**（首次每本约 1~2 分钟）；
3. 之后生成的学习内容会引用教材原文段落，并标注 `《书名》 第X页` 出处。

**页码校准（已自动完成）**：建库时自动推断每本教材 PDF 物理页码与印刷页码的偏移，
引用页码为**印刷页码**（学生可直接按页码翻书）；同时自动剔除封面/编委/前言/目录块。
存量旧索引用侧边栏「📐 校准页码并清理前言/目录」一键修复（不重新向量化）。
检索带相关性阈值（`PBL_MIN_SCORE`，默认 0.55）：与问题不相关的教材段落不会被喂给模型，避免硬凑引用。

注意：扫描版 PDF（图片型）无法抽取文字，请使用可复制文本的电子版。

## 四、文献来源说明

- **PubMed（自动）**：每个问题自动用英文检索词查询 PubMed 官方 API，**限定近 7 年文献**，返回的都是真实文献（含 DOI 可验证）。**每个问题的参考文献不超过 5 篇**。**参考文献与正文标注一一对应**：只有被正文标注引用的文献才进文献表，且文献表保证非空（有检索结果时兜底取最相关一条）；**学习内容小节的教材出处（如《内科学》（第10版）第261页）会自动对账进参考文献表**（含主编/版次/页码归并，PPT 与 Word 均生效）；**学习内容生成强制纳入期刊文献**：模型须把 PubMed 检索结果写进正文并标注，若生成结果漏引，系统自动补一轮「把已检索文献补标到对应句子」；问题缺检索词时自动补齐再检索；智能体审校修订时保留原有引用。**参考文献列表只来自检索结果，AI 不生成文献条目**，杜绝编造。多词检索式先 AND（求准）自动降级 OR（求全）。
- **GB/T 7714-2015 顺序编码制**：AI 生成时在正文句末打引用标记，系统自动转换为论文样式——正文出现上标 `[1]`，文末按首次引用顺序编号（临床应用部分不标文献，专注联系病例）；**教材依据生成 [M] 专著条目**（如 `万学红, 卢雪峰. 诊断学[M]. 10版. 北京: 人民卫生出版社, 2024: 125-128.`），同一本书多页引用合并为一条；期刊为 [J] 条目（作者「姓+缩写」，超 3 人加 et al，含年/卷/期/页码/DOI）。
- **教材著录目录**：`pbl/book_catalog.json` 存每本教材的著录信息（书名/版次/出版地/出版社/年份/主编已预填）。主编由 `tools/fill_catalog_authors.py` 从教材 PDF 编委页自动抽取（个别识别失败的请按版权页手动补齐），改完重新生成即生效。
- **中文文献（半自动）**：知网无开放 API。系统为每个问题生成知网检索式（在 ① 中复制），检索后把题录在 ② 的「手动添加文献」中录入（支持期刊[J]/书籍[M]两种类型），会一并按 GB/T 格式排进 Word。

### 案例存档（自动）

- **最新存档**：每次界面刷新自动写 `cases/_autosave.json`——浏览器关掉/崩溃后，重开在侧边栏「💾 案例存档」点 **⏪ 恢复上次案例** 即可；
- **历史快照**：每次整理/生成/审校/载入后自动落一份时间戳快照到 `cases/history/`（保留最近 30 份），改坏了可随时回退到任一历史版本。

### 思维导图的使用节奏

一个 PBL 病例跨多次课：**每节课**生成并修改对应问题的学习内容与临床应用（Word 默认不含导图）；**最后一节课结束**后在 ③ 区点「AI 生成疾病导图」，系统汇总全部学习内容，以疾病为中心生成总结性知识导图，单独导出。

## 六、设计要点（二次修改为何快）

所有内容围绕一份**案例 JSON**（可在 ①②③ 中随时下载存档）：
- **字段级局部重生成**：改一个字段只重算一个字段，不重跑整个流水线；
- **内容与版式解耦**：Word 字体字号、PPT 主题配色调整不触发重新生成；
- **PPT 大纲层可编辑**：每页标题/要点改完直接重渲染，不消耗 AI 调用。

## 六、开源说明与免责

- **本仓库不含任何 API Key、真实病例与教材**：`.env` 需自行配置（见 `.env.example`）；
  教材知识库（`knowledge_base/`）请用你自己的教材 PDF/DOCX 构建，向量化走智谱 embedding-3。
- **模板版权**：`pbl/templates/` 里的 Word/PPT 模板来自学校公共模板，仅作开箱示例；
  如认为侵权请联系仓库维护者删除，你也可以在界面里上传自己的模板替换。
- **医学内容免责**：AI 生成的学习内容、参考文献标注、临床应用与数据**必须经过使用者本人
  的医学专业核对**后方可用于教学/提交；模型可能生成不准确甚至错误的表述（表格中的试验
  数据尤其需要核对）。本项目仅辅助整理，不构成医学建议。
- **隐私**：所有病例数据只存在本地（`cases/`、`output/`），不会上传到任何服务器；
  请勿把你自己的真实病例目录提交到公开仓库。
