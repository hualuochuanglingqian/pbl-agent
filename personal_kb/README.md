# 个人医学知识库（混合检索 + 重排 + 页码引用）

一个本地 Streamlit 知识库，直接复用 PBL 智能体已经建好的 43 本教材索引：

- **语料**：43 本教材 + 4 套自测题库，共 **29,281 个知识块**
- **检索**：向量检索（智谱 embedding-3）+ BM25 关键词检索，混合排序
- **重排**：把候选块交给 DeepSeek 按相关性重排
- **章节元数据与过滤**：命中页自动映射到“篇/章”，引用显示为“《内科学》第480页（第五篇 泌尿系统疾病 · 第二章 原发性肾小球疾病）”；选中单本教材后，侧边栏可再限定到某一篇/章
- **回答**：只依据教材片段生成；命中页会整页回填，文末参考来源由系统按真实命中页列出（书名 + 页码 + 章节）
- **界面**：限定来源、混合/纯向量/纯关键词、候选数、引用数、只检索模式、分数显示

## 快速开始

```bash

from pbl import textbook

```

## 检索与回答是怎么做的

1. **向量检索**：`textbook._load_index()` 加载已归一化的向量，查询向量由智谱 `embedding-3` 生成，余弦相似度。
2. **BM25**：`jieba.lcut_for_search` 分词 + `rank_bm25.BM25Okapi`。
3. **融合**：两路分数各自 min-max 归一化后加权，默认 `0.65 * 向量 + 0.35 * BM25`；可在界面切换纯向量/纯关键词。
4. **过滤**：先按“限定来源”过滤，再排序。
5. **重排**：取候选 top 30，交给 DeepSeek 输出相关性序号；不足 4 条时用融合分数补齐。
6. **生成**：把 top 4–6 个命中页整页回填（每页最多 3500 字），并按“书名+页码”去重、每个来源最多 2 条；提示词要求“只依据片段、数值/单位逐字照抄、不同教材分别列出、证据不足就说没有”；正文不写编号，文末参考来源由系统按真实命中页生成。

## 自测

左侧页面导航点「2 自测」，流程按学习通的自测页面重做：

1. **我的自测**：显示待做/已完成、剩余时间；可继续作答、查看结果、删除。
2. **新建自测**：
   - 自测标题、模拟测验/刷题自测、自测时间；
   - 题目来源：平台题库（1,044 题）或错题本；
   - 选题方式：随机抽题、从文件夹选题、按题型选题、按主题选题；
   - 模拟测验交卷后统一看答案，刷题自测每题可点「查看答案」。
3. **答题页**：左侧题目、右侧答题卡和已答进度；交卷后自动判分。
4. **结果页**：得分/正确率、逐题对错、正确答案、解析、来源；可「再做一遍」。
5. **错题本**：答错自动收录，可按来源查看、错题重练、清空。

平台题库的 1,044 题来自 4 套已导出的平台自测（医学遗传学 447、循环药病理 302、消化病理药理 92、综合自测 185），含题干、选项、正确答案、解析。

## 检索自检

```bash
python eval.py --n 30
python eval_golden.py            # 默认检索
python eval_golden.py --rewrite  # 开启多查询改写
```

`eval.py` 是“用知识块首句反查原页”的自检，适合发现索引/检索回归；`eval_golden.py` 是人工标注的自然问句评估，更接近真实问答。黄金集目前 12 题，建议逐步扩到 50–100 题。

## 性能

- 首次加载索引 + BM25 约 **8–15 秒**（190 MB 向量 + 2.9 万块分词）。
- 单次提问：向量化 1–2 秒 + 检索 <1 秒 + LLM 重排 2–5 秒 + 生成 3–8 秒。
- 如果只检索不生成，通常 **3–5 秒**。

## 隐私与边界

- 索引和 BM25 缓存都在本地；只有**查询文本和检索到的片段**会发给智谱/DeepSeek。
- 医学数据如涉及病人隐私，建议把 `pbl.llm` 切换成本地模型（Ollama/vLLM），或先脱敏。
- 页码是 PBL 项目校准后的**课本印刷页码**；个别 PDF 若偏移识别失败，页码可能按物理页显示。
- 生成答案可能出错；**“查看原文依据”里的整页原文才是最终依据**，考试/临床决策请回查原文。
- 不限定来源时，系统会跨教材综合；不同教材的诊断标准/单位可能不同（如成人 vs 儿童），甚至有的教材本身把 g/d 写成 g/L。问具体某本教材时，先在左侧“限定来源”里选中它；跨教材答案会分别列出各教材原文，不合并成一个标准。
